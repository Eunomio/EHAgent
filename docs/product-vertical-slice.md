# v0.2.0 可解释Agent纵向切片

## 目标

用一个“走廊中部纸箱”场景证明产品链路可被真实操作和验收：

```text
测试素材 → 观察 → 画质门控 → 风险规则 → 整改任务 → 住户反馈 → 整改后复查
```

本切片验证产品交互、任务状态机和数据来源隔离，不验证视觉模型准确率或真实设备能力。

## 数据来源

|来源|输入方式|结论生成方式|界面要求|
|---|---|---|---|
|REPLAY|三份内置固定素材|预置质量与空间关系结果经过确定性规则|永久显示“演示任务/内置回放素材”|
|MANUAL|工程人员上传本地图片并选择预期案例|人工标签经过同一任务规则|永久显示“演示任务/人工标注素材”|
|REAL_DEVICE|v0.2.0未实现|不得声称可用|不得出现在演示结果中|

上传图片只保存在本机SQLite任务证据字段中，限制为图片Data URL且请求体最多3 MB；前端在1.5 MB原始文件处提前拦截。后续接入正式素材库时改为受控文件存储与留存策略。

## 工程测试台

- 工程密钥只存入当前标签页的`sessionStorage`；
- 只有`COMMISSIONING`或`MAINTENANCE`可以运行演示素材；
- 展示素材预期结果，不把预置结果包装成自动识别；
- 分阶段展示“读取素材、检查画质、判断风险、生成建议”；
- 画质不足时必须停在门控阶段，不生成风险任务；
- 分析完成后可直接打开住户端预览。

## 住户端

- 首屏最多显示一条任务；
- 演示任务必须在卡片顶部显示黄色来源条；
- 默认正文不小于18px，并允许两档字号调节；
- 四个动作保持固定：已处理、稍后处理、这里没有风险、暂停此类提醒；
- 每个动作至少76px高，并在提交前二次确认；
- 支持浏览器中文语音朗读；
- 无结果时不得显示“当前安全”，只允许显示“没有待处理的演示任务”。

## 状态机

|动作/输入|原状态|结果状态|
|---|---|---|
|生成走廊障碍任务|无活动任务|OPEN|
|再次运行障碍素材|OPEN/DEFERRED/RESCAN_PENDING|更新同一任务并保持去重|
|已处理|OPEN/DEFERRED|RESCAN_PENDING|
|稍后处理|OPEN/DEFERRED|DEFERRED，默认30分钟|
|这里没有风险|OPEN/DEFERRED|DISPUTED|
|暂停此类提醒|OPEN/DEFERRED|PAUSED|
|运行整改后素材|RESCAN_PENDING|RESOLVED|

`DONE`不得直接产生`RESOLVED`。同一`Idempotency-Key`重复提交只返回首次结果，不新增反馈记录。

## 验收用例

1. 未提供工程密钥时，演示素材接口返回401；
2. `UNINITIALIZED`运行素材时返回409；
3. 障碍Replay生成一条`OPEN`任务并显示四个Agent阶段；
4. 住户端显示任务、证据、自然语言原因、建议和REPLAY标签；
5. 点击“已处理”后进入`RESCAN_PENDING`而不是`RESOLVED`；
6. 整改后Replay将待复查任务变为`RESOLVED`；
7. 模糊素材返回`EVIDENCE_INSUFFICIENT`且不创建任务；
8. 上传图片结果为`MANUAL`，界面不出现自动识别声明；
9. 四类反馈保存审计记录，重复幂等键不重复写入；
10. `ACTIVE`正式页面不得展示Replay/Manual任务，也不得将其计入正式指标。

## 后续开发闸门

- 在视觉模型接入前，不得把上传素材按钮改写为“AI自动识别”；
- 在真实设备PoC通过前，不得提供`ACTIVE + REAL_DEVICE`演示入口；
- 真实图片证据必须迁移到有授权、留存和删除机制的文件存储后才能进入用户测试；
- 下一阶段需补浏览器端到端测试、任务中心、争议复核和正式来源隔离查询。
