# Actual 界面对齐记录（0.19.0 / code30）

## 参照与交付范围

参照为本地 `EHAgent/` 中基于 `adfac15` 的最新 demo 工作区，包括未提交的每日会话和睡眠概览更新。开发与交付位于独立工作区 `EHAgent-main-cleanup/`，基线为 main 的 `0b6c27e`。原 demo 工作区的源码、聊天、演示进度均保留。

main 继续仅构建 actual。界面沿用最新 demo 的组件和视觉规则；摄像头操作仍使用真实设备，睡眠刷新仍调用实际同步接口，没有恢复 demo 版本、内置视频或自动样例导入。

## 页面核对

| 页面或组件 | 对齐结果 |
| --- | --- |
| 首页 | 保留生活模块、内嵌聊天、拖动排序；迁入每日会话切换与旧历史回写保护；关怀卡片不额外展示触发原因；窄屏大字号标题允许换行 |
| 安全结果与提醒 | 六态颜色、等级文字和风险框标签统一；中风险橙色、高风险红色；按同一任务对应结果显示提醒颜色 |
| 检查交互 | 检查中隐藏旧结果和旧框；显示进行中状态；失败有重新检查；完成后显示绿色完成卡片及建议；操作成功提示可见 |
| 实时摄像头 | 保留主动打开、关闭、全屏、方向控制、识别与暂停；继续保留联系家人和延后提醒 |
| 睡眠 | 上周概览默认收起，可展开7晚睡眠柱图、作息时间轴、入睡/起床、心率/呼吸；昨晚呼吸、心率、离床三列；有数据与无数据页面均去掉起夜关注卡片 |
| 近期趋势 | 保留点选晚次和当晚详情；缺失值显示“—”；“最近两晚已有好转”仅在两晚数据完整且均较此前减少时显示 |
| 聊天和语音 | 保留共用布局、输入和历史；迁入最新 demo 的每日会话交互；保留 main 对未实现支持动作的过滤 |
| 白噪音 | `WhiteNoisePlayer.kt` 与 `WhiteNoisePlayerCard.kt` 和本地 demo 内容相同 |
| 隐私与我的 | 共用的权限、暂停、画像、连接、联系人和反馈界面保留；没有演示管理入口 |
| 悬浮助手与播放器 | 继续使用同一组件；实时画面必要控制保留 |

## 后端配套

- actual 的 dashboard 和 sleep 请求显式携带 `data_mode=actual`，排除演示睡眠及不匹配的睡眠关怀事件。
- 上周概览按北京时间上一自然周聚合，排除演示记录及质量不足记录，缺失日期和数值保留为空。
- `/api/v1/devices/c6c/safety/latest` 新增 `checking`，来自实际分析锁；返回任务标识以避免异步刷新时给旧任务套用新等级。
- 完整功能需配套本次后端。此次没有重启原工作区运行的服务。
