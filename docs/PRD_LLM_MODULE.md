# PRD：Windows 本地 Agent 的 LLM 模块

> 版本：v1.1
>
> 日期：2026-08-24
>
> 所属产品：居安 Agent

## 1. 当前职责

LLM负责把已经确认的睡眠数据和老人反馈整理成简短中文，并支持“小安”生活助手对话。生命体征数值、个人基线、帮助请求和任务状态由设备数据及固定程序确定。

当前自动通道检查由 VLM 读取图片、固定规则校正风险并生成整改动作。通道安全主流程不会再把图片结果交给第二个 LLM 改写，也不会使用传统目标检测模型。旧版 `POST /api/v1/ingest/safety-results` 仍可调用安全文案方法，仅用于兼容早期脚本。

## 2. 用户场景

### 2.1 睡眠结果分析

一晚睡眠数据写入后，LLM根据睡眠时长、平均呼吸频率、平均心率、可用的离床数据和最近记录生成生活化总结。文案只描述记录和变化。

### 2.2 老人反馈整理

老人输入使用感受、身体感受或帮助说明后，系统保存原文，LLM生成简短摘要、反馈类别和是否建议人工跟进。摘要不会覆盖原文。

### 2.3 “小安”生活助手

后端向小安提供当前安全状态、最近睡眠、家庭设置和最近对话。小安回答家庭信息与一般生活问题；天气、新闻、政策等时效内容可以附带公开来源。联系家人等实际动作需要用户再次确认。

### 2.4 旧版安全结果兼容

外部程序通过 `POST /api/v1/ingest/safety-results` 回传旧版 `obstacle` 结果时，LLM可以根据位置、物品和说明生成标题、解释与建议。当前 C6c 自动监测和 APK 不依赖该入口。

## 3. 输入与输出

| 场景 | 输入 | 结构化输出 |
|---|---|---|
| 睡眠分析 | 当晚真实字段、最近最多7晚记录 | `summary`、`attention`、`question` |
| 反馈整理 | 反馈主题和老人原文 | `summary`、`category`、`needs_follow_up` |
| 生活助手 | 后端生活摘要、用户问题、最近对话 | 回答、使用的信息、公开来源、待确认动作 |
| 旧安全兼容 | 位置、物品、外部程序说明 | `title`、`explanation`、`suggestion` |

结构化字段设置长度上限并由 Pydantic 校验。模型缺少字段、返回无效 JSON、超时或未配置时使用对应固定模板。

## 4. 运行和配置

配置只保存在 Windows 后端 `.env`：

```dotenv
EH_LLM_ENABLED=true
EH_LLM_PROVIDER=openai
EH_LLM_API_KEY=
EH_LLM_MODEL=gpt-5.4-nano
EH_LLM_API_BASE=https://api.openai.com/v1
EH_LLM_TIMEOUT_SECONDS=15
EH_ASSISTANT_WEB_SEARCH_ENABLED=true
EH_ASSISTANT_LOCATION=上海市
```

APK不会接触 API Key。`EH_LLM_ENABLED=false` 或没有 Key 时，睡眠与反馈使用固定模板；生活助手返回当前可用的基础答复。

VLM和TTS分别使用 `EH_VLM_*` 与 `EH_TTS_*` 配置。三类服务可以共用兼容接口的地址和密钥，但职责及失败处理保持独立。

## 5. 内容要求

- 使用老人日常能理解的中文，一次只给出一个优先动作；
- 不增加输入中没有出现的人物、物品、生命体征或处理结果；
- 睡眠内容只描述数值、时间和“与个人平时相比”的变化；
- 身体不适时建议联系家人或专业人员；
- 原始设备数据、个人基线、VLM结果和LLM文案分开保存；
- LLM不能修改风险等级、生命体征数值、帮助请求或任务状态；
- 自动拨号、联系家属和删除记录等动作需要产品规则与用户确认。

## 6. 降级模板

- 睡眠：`昨晚共睡眠{时长}。平均呼吸频率{数值}次/分，平均心率{数值}次/分。`
- 反馈：截取原文前160字作为摘要；涉及求助、安全、跌倒、疼痛或不适时建议人工跟进。
- 旧安全兼容：`{位置}发现{物品}，可能影响通行。建议将{物品}移到走道外。`

## 7. 验收

- 配置有效 Key 后，睡眠与反馈场景能取得通过结构校验的结果；
- 小安可以引用后端提供的家庭信息，时效内容能够返回可打开的来源；
- 联系家人的建议只有在用户确认后才创建帮助请求；
- LLM不能改变睡眠原始数值、个人基线或安全任务状态；
- 超时、限流、无 Key 和无效 JSON 时使用固定模板；
- 老人反馈同时保存原文和摘要；
- 日志和住户接口不包含 API Key；
- 关闭 LLM 后，VLM 自动通道检查、风险框、通知、TTS和复查仍可使用。
