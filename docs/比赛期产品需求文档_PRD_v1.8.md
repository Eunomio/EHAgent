# 比赛期产品需求文档（PRD）

> 文档版本：v1.8  
> 最近修订：2026年8月17日  
> 目标提交日期：2026年9月5日  
> 产品定位：比赛可运行原型  
> 产品形态：安卓APK住户端 + Windows本地Agent + Windows Web工程台

本次修订完成无感睡眠助手的设备级接入数据契约。睡眠设备使用独立序列号绑定，平台报告可安全推送、去重更新并展示睡眠构成、得分、心率和呼吸频率。

## 1. 本次要交付什么

本次交付重点是让主要功能可以安装、操作、测试和演示。住户使用安卓APK，Windows电脑运行本地Agent和工程台。

住户端首页优先展示两个核心生活功能和一个共用入口：

1. 通道安全；
2. 睡眠与身体趋势；
3. 帮助与设置。

通道安全完成主要Agent闭环，使用真实C6c和萤石开放平台完成取图、风险判断、整改提醒与复查。睡眠模块接入无感睡眠伴侣的睡眠、呼吸频率和心率数据，完成个人趋势总结、本人确认和请求家人联系。帮助与设置提供家属响应、摄像头暂停和数据控制。访客确认保留为扩展演示，不占用主线算法开发资源。

当前使用安卓手机开发和真机测试，同时用Android Emulator检查手机和平板尺寸。以后可根据需要购买安卓平板，并在拿到萤石RK3后继续适配。

## 2. 产品目标

- 老人打开APK后能直接看懂通道安全、睡眠趋势和帮助入口；
- C6c在一个固定非隐私通道完成真实取图和风险复查；
- 通道出现明显障碍物后，页面给出位置、原因和处理动作；
- 同一风险经过连续确认后只主动提醒一次，卡片保留到处理完成；
- 每晚生成包含睡眠时长、呼吸频率和心率的总结；
- 数据满足条件时展示最近7天趋势，只提示“与平时不同”；
- LLM把视觉模型和固定规则的结果转写为简短、具体、可执行的老人端文案；
- LLM不可用时自动使用固定模板，安全任务和睡眠页面仍可正常使用；
- 老人能从任意主页面打开“小安”，用文字或语音提出问题；
- 小安能引用当前安全提醒、最近睡眠和家庭设置，也能回答一般生活问题；
- 天气、新闻、政策、交通和近期诈骗信息等时效内容按需查询，并给出可打开的来源；
- 联系家人等实际动作先展示确认按钮，老人确认后执行；
- 老人可以请求家人协助处理环境问题或联系本人；
- 老人可以暂停摄像头或某类提醒；
- 新来访者确认作为扩展演示，不输出诈骗或身份结论；
- 工程人员能在Windows工程台输入素材、运行测试、查看结果和调整模型配置；
- APK能在安卓手机安装运行，并能连接同一局域网内的Windows Agent；
- 比赛演示可以通过初始化数据重复执行。

## 3. 产品形态与角色边界

### 3.1 安卓住户端

住户端只展示老人日常需要的信息和操作：

- 通道检查状态与风险提示；
- 当天睡眠、呼吸频率和心率总结；
- 最近7天的个人趋势；
- 家属联系状态、摄像头暂停和提醒设置；
- 扩展来访确认；
- 清晰的大按钮和中文语音。
- 全局生活助手、语音提问、回答朗读和信息来源。

APK中不显示素材上传、训练数据、模型、阈值、日志、Replay、Manual、接口地址、内部任务编号和测试状态。Agent地址由工程人员在安装配置中设置。

### 3.2 Windows工程台

工程台用于：

- 接入和测试摄像头；
- 接入和测试无感睡眠伴侣数据；
- 上传图片或视频素材；
- 创建人工测试场景；
- 查看识别结果、规则结果和任务状态；
- 管理训练、验证和测试素材；
- 调整模型版本、阈值和规则；
- 初始化或重置比赛演示数据；
- 查看真实设备、授权导入、回放和人工数据的来源；
- 查看运行日志和导出测试结果。

工程台只在Windows本机打开，不设置Engineering API Key。工程接口只监听本机地址，不向局域网或公网开放；安卓住户端只访问住户功能接口。

### 3.3 Windows本地Agent与LLM模块

Windows本地Agent负责连接设备、保存状态、执行固定规则、调用视觉模型、管理任务闭环和向安卓端提供数据。LLM是Agent内部的解释组件，输入只使用已经结构化的数据，不代替视觉模型和风险规则作结论。

LLM处理四类内容：

- 根据物品类别、位置、ROI判断和模型说明，生成老人易懂的风险解释与整改建议；
- 根据真实睡眠时长、呼吸频率、心率、离床次数和近7晚统计，生成生活化睡眠总结；
- 将老人提交的使用感受、身体感受或帮助说明整理成简短摘要，供家属或工程人员查看；
- 在不改变任务状态的前提下，调整文案长度、称呼和表达方式。

LLM不得：

- 根据图片自行确定是否存在风险；
- 修改视觉模型输出、ROI判断、连续确认次数或任务状态；
- 根据睡眠、呼吸频率和心率诊断疾病；
- 生成未出现在输入数据中的人物、物品、生命体征或处理结果；
- 自动拨号、联系家属、删除记录或控制设备。

LLM API Key只保存在Windows电脑的`.env`，不写入APK、数据库、日志或GitHub。每次调用保存用途、实体ID、使用模型、结果来源和时间，不保存API Key。LLM超时、限流、返回格式错误或未配置时，Agent立即使用对应固定模板。

## 4. 安卓住户端信息架构

### 4.1 首页

首页使用三个大卡片，不以设备作为一级入口。

|卡片|主要内容|主要动作|
|---|---|---|
|通道安全|C6c在线/暂停状态、检查区域、待处理风险、最近检查时间|检查一下、查看详情|
|睡眠与身体趋势|昨晚睡眠时长、呼吸频率、心率、是否与个人平时接近|查看详情、回应提醒|
|帮助与设置|家属联系状态、摄像头状态、提醒开关|联系家人、暂停摄像头、调整提醒|

首页不创建教学任务、演示任务或测试任务。没有正式结果时显示“暂时没有新的记录”或对应模块的自然提示。

### 4.2 适老化要求

- 默认正文字号不小于20sp，重要数字和标题使用更大字号；
- 主要按钮触控高度不小于48dp；
- 一屏只突出一个主要动作；
- 文字和背景保持高对比度；
- 状态同时使用文字与颜色表达；
- 重要提醒支持中文语音，语音内容与页面文字一致；
- 手机宽度使用单列，平板宽度使用双列、三列或主从布局；
- 页面不出现横向滚动，关键按钮不依赖精细点击；
- 文案自然、简短、具体，直接说明发生了什么和可以怎么做。

### 4.3 全局生活助手“小安”

#### 用户场景

- 老人在首页、安全、睡眠或“我的”页面看到右下角“问小安”，点击后打开完整对话页；
- 首次打开时看到“昨晚睡得怎么样”“今天适合出门吗”“这个电话像诈骗吗”“帮我联系家人”四个常用问题；
- 老人可以输入文字，也可以点击麦克风说出问题；发送后当前问题立即显示，回答完成后显示在下方；
- 老人点击回答下方的扬声器即可朗读全文；
- 回答使用了最近睡眠、安全提醒等家庭信息时，页面显示“参考了：最近一次睡眠”等简短说明；
- 回答包含天气、新闻、政策、交通或近期诈骗信息时，页面显示来源卡片，点击后用浏览器打开原页面；
- 老人说“帮我联系家人”后，页面显示“确认联系家人”；只有点击确认后，家庭帮助列表才新增请求；
- 关闭再打开应用时，最近一次对话仍可继续。

#### 页面内容与交互

- 顶部显示“小安”和返回按钮；
- 中部按时间展示本人问题和小安回答，本人消息与回答使用不同颜色；
- 底部固定展示语音按钮、文字输入框和发送按钮；
- 回答等待期间显示“小安正在想…”；
- 家庭服务暂时无法连接时，保留已有对话并提示稍后重试；
- 页面不展示模型名称、接口地址、联网工具、调用状态或内部记录编号。

#### 使用信息规则

每轮对话只整理回答当前问题所需的家庭摘要，包括最近一次睡眠、当前安全提醒、摄像头与睡眠提醒开关、设备连接状态和家人称呼。历史对话最多取最近10轮。原始摄像头画面、设备密钥、联系电话和历史完整传感器序列不发送给生活问答。

天气、新闻、政策、交通和近期诈骗信息可能变化，小安按问题需要查询公开信息并返回来源。普通闲聊或已经能由家庭摘要回答的问题无需查询。涉及身体不适时提供清晰的下一步建议；胸痛、呼吸困难、失去意识或正在跌倒等紧急描述优先提示呼叫急救和联系身边的人。

#### 验收结果

- 四个主页面都能在一次点击内打开“小安”；
- 文字提问、语音转文字、发送、回答朗读均可在安卓真机完成；
- 输入“昨晚睡得怎么样”后，回答中的睡眠时长、心率和呼吸频率与首页最近记录一致；
- 输入一个需要近期信息的问题后，回答至少显示一个可正常打开的来源；
- 输入“帮我联系家人”后，点击确认前帮助列表不新增记录，点击确认后只新增一条；
- 重启应用后能恢复最近一次对话；
- 后端未配置生活问答服务时，安全和睡眠问题仍能得到基于现有数据的简短回答；
- 回答失败时页面不丢失已有消息，可以再次发送。

## 5. 通道安全模块

### 5.1 首页卡片

卡片展示：

- C6c在线、离线或已暂停；
- 当前检查区域，例如“卧室外走道”；
- 当前未处理风险数量；
- 最重要的一条提示；
- 最近检查时间；
- “检查一下”和“暂停摄像头”按钮。

首页不默认持续播放直播。用户主动进入详情页时才允许打开画面。

### 5.2 二级页面

页面包含：

- 摄像头状态和当前检查区域；
- 用户主动打开的实时画面或最近一次风险缩略图；实时画面由萤石Android SDK的EZPlayer按设备和通道取流，可播放C6c的H.264/H.265码流；
- 通道ROI示意和隐私遮罩；
- 当前风险卡片；
- 最近已完成记录；
- 数据保存和自动删除时间。

摄像头支持以下操作：

- 检查一下；
- 启动或停止画面；
- 暂停或恢复自动检查；
- 修改区域名称；
- 查看通道ROI和隐私遮罩；
- 删除已保存的风险图片。

### 5.3 环境风险Agent闭环

```text
C6c真实抓图、回放或工程素材
→ 检查画面是否清晰、是否为当前固定视角
→ 判断纸箱、袋子、鞋、凳子或明显电线是否侵入通道ROI
→ 第一次发现只记录，连续第二次仍存在才主动提醒
→ 生成“位置 + 发现内容 + 建议动作”
→ 老人选择已处理、稍后处理、需要家人帮忙、这里没有风险或暂停提醒
→ 再次抓图检查
→ 更新为已完成、继续保留或转为家属待办
```

同一区域、同一风险类型只保留一张活动卡片。重复识别只更新时间，不重复主动弹窗或播放语音。风险处理完成后从当前风险区移到最近记录。

自动识别范围只包含一个固定通道内的明显物品侵入。比赛版不自动判断地面湿滑、照度、物品重量、身体不适或未来是否会跌倒。

### 5.4 防打扰与隐私规则

- 连续两次检查都发现同一风险才主动提醒；
- “稍后处理”默认2小时后提醒一次，每天最多一次；
- “这里没有风险”当天不再重复提醒，记录给工程台复核；
- 夜间不主动播放环境整改语音，次日上午再提醒；
- 默认不保存连续视频；
- 无风险图片处理完成后删除，只保存结构化结果；
- 风险图片按设置的期限自动删除；
- 暂停后停止应用侧自动取图，并在首页持续显示“摄像头已暂停”。

### 5.5 通道安全模块验收

- 能通过萤石开放平台取得C6c设备状态和有效图片；
- 连续20次真实取图至少19次成功，失败时不生成风险结论；
- 固定通道和ROI可以配置并保存；
- 第一次发现风险只记录，连续第二次发现后生成一条提醒；
- 提醒包含位置、发现内容和建议动作；
- “已处理”后可以重新抓图并更新结果；
- “需要家人帮忙”可以生成家属待办；
- 暂停后不再自动取图，恢复后可以继续检查；
- 相同风险不会重复创建任务或连续播放语音；
- 真实设备、回放和人工素材保持独立来源标记。

## 6. 睡眠与身体趋势模块

萤石无感睡眠伴侣具备无感监测睡眠、呼吸频率和心率的设备能力，并可形成睡眠报告；官方产品资料还提到离床未归、心率异常和体动异常等提醒。比赛版只使用当前账号和开放接口能够真实取得的字段，不根据缺失字段生成模拟的正式结果。

### 6.1 首页卡片

展示昨晚最近一次有效睡眠：

- 开始时间和结束时间；
- 睡眠时长；
- 平均呼吸频率，单位“次/分”；
- 平均心率，单位“次/分”；
- 与个人最近7晚是否接近；
- 一句状态提示。

当设备或接口没有返回某项数据时，该项显示“暂未同步”，不使用0填充。首页只展示平均值和自然语言趋势，不展示复杂波形。

### 6.2 二级页面

页面包含：

- 昨晚睡眠开始、结束和总时长；
- 呼吸频率的平均值；接口提供时展示最低值、最高值和夜间趋势；
- 心率的平均值；接口提供时展示最低值、最高值和夜间趋势；
- 离床次数、夜间觉醒次数或睡眠周期，仅在真实字段可用时展示；
- 最近7晚的睡眠时长、平均呼吸频率和平均心率趋势；
- 当前提醒与本人回应；
- 数据来源时间和最近同步状态。

比赛版按以下顺序接入数据：

1. 无感睡眠伴侣经萤石开放平台或获批接口返回的真实数据；
2. 设备或萤石云视频APP授权导出的数据；
3. 明确标记的回放或预置演示数据。

工程台完整标记数据来源。正式统计只使用真实设备或符合研究授权的导入数据。

### 6.3 数据字段与质量要求

最小数据对象包含：

- 本地睡眠记录ID和平台报告编号；
- 无感睡眠助手独立设备序列号，住户端不显示；
- 报告日期和时区；
- 睡眠开始和结束时间；
- 总睡眠时长；
- 呼吸频率平均值及单位；
- 心率平均值及单位；
- 数据生成时间和收到时间；
- 数据来源；
- 数据完整性或设备提供的质量状态。
- 报告状态，包括初步、最终或修正；

接口提供时继续保存睡眠得分、清醒时长、浅睡时长、深睡时长和快速眼动时长。每个时序采样点可以包含采样时间、呼吸频率、心率、是否在床和体动数值；每个睡眠阶段区间包含开始时间、结束时间和阶段类型。

接口提供采样序列时，再保存呼吸频率和心率的时间戳序列、最低值、最高值。接口只提供夜间汇总时，页面只展示汇总值，不补造曲线。

呼吸频率、心率存在缺失、时间错位、设备离线或质量不足时，该晚不参与个人基线计算。原始设备数值和Agent生成的趋势结论分开保存。

### 6.4 个人基线与提醒规则

- 以一晚有效睡眠为一个总结单位；
- 同一次睡眠只主动提醒一次；
- 数据更新时更新原有总结，不连续创建新提醒；
- 至少有7晚有效数据后才生成个人趋势；
- 睡眠时长连续2晚比个人最近7晚中位数减少30%以上时，提示“最近两晚睡眠时间和平时有些不同”；
- 呼吸频率和心率在比赛版优先展示趋势，不自行输出疾病或紧急结论；
- 若设备或平台提供原生异常事件，系统可以转为“设备提示这项数据需要关注”，同时保留事件来源；
- 本人回应包括“我没事”“希望家人联系我”“这几天情况特殊”“暂停这类提醒”；
- 选择“希望家人联系我”后生成家属待办；
- 没有数据时显示“昨晚的睡眠数据暂未同步”。

提示文案只说明数据与个人平时是否不同。页面不输出抑郁、认知障碍、失眠、心脏病、呼吸系统疾病等判断。老人表示身体不舒服时，页面提示联系家人或按既有方式寻求医疗帮助。

### 6.5 实时离床、呼吸和心率边界

- 设备具备实时检测能力，不等于当前开放接口一定提供实时采样；
- 只有实际接口能够返回事件级离床数据且端到端延迟通过测试，才开启实时离床提醒；
- 只有实际接口提供实时呼吸频率或心率采样，页面才显示“当前值”；
- 接口只提供睡眠报告时，统一展示为“昨晚数据”；
- 离床实时提醒启用前需验证事件时间、延迟、补发和误触发；
- 当前没有可控智能灯具，比赛版不承诺自动开灯；睡眠伴侣自身的夜灯功能只按设备实际可控制能力使用。
- 若开放接口提供夜灯开关或模式控制，可在设置页增加“跟随设备设置”；若接口未提供，继续使用睡眠伴侣原有的本机或萤石云视频APP设置。

### 6.6 睡眠模块验收

- 能接收至少一晚真实睡眠伴侣数据或授权导出数据；
- 能展示睡眠时间段、总时长、平均呼吸频率和平均心率；
- 缺少呼吸频率或心率时显示“暂未同步”，不显示0或模拟数值；
- 有7晚有效数据时能展示睡眠时长、呼吸频率和心率趋势；
- 规则触发后能完成本人回应；
- “希望家人联系我”能生成家属待办；
- 同一睡眠记录更新后不重复主动提醒；
- 相同设备序列号和平台报告编号重复推送时更新同一记录；
- 未携带接收凭证、缺少设备序列号或序列号不匹配时拒绝写入；
- 真实设备、授权导入和预置数据保持来源隔离；
- 实时字段只在接口真实提供并通过延迟测试时展示；
- 预置演示数据可初始化和重置。

## 7. 帮助与设置模块

### 7.1 首页卡片

展示：

- 第一联系人及当前是否已配置；
- 待处理家属事项数量；
- 摄像头正在检查或已暂停；
- 睡眠提醒开启或已暂停。

主要动作：

- 联系家人；
- 暂停或恢复摄像头；
- 暂停或恢复睡眠提醒；
- 查看数据保存设置。

### 7.2 家属待办闭环

家属待办可以由以下动作生成：

- 通道风险任务选择“需要家人帮忙”；
- 睡眠提醒选择“希望家人联系我”；
- 老人在帮助页主动选择“联系家人”。

比赛版使用同一局域网内的家属Web页面，不接入短信、电话或微信。家属页显示请求类型、发生时间、老人希望得到的帮助和当前状态，提供“已看到”“已联系”“已完成”三个操作。

环境整改请求不设置紧急倒计时。睡眠趋势请求也不自动标记为紧急。系统记录老人请求到家属查看、联系和完成的时间。

### 7.3 隐私与数据设置

- 查看C6c当前检查区域和隐私遮罩；
- 一键暂停或恢复自动取图；
- 设置风险图片自动删除期限；
- 删除已保存的风险图片；
- 暂停睡眠趋势提醒；
- 查看哪些数据会发送给家属；
- 家属默认只看到风险摘要、老人主动请求和需要的下一步，不查看连续视频或完整生命体征曲线。

### 7.4 帮助与设置验收

- 三种入口均能生成一条家属待办；
- 家属可以完成查看、联系和完成回执；
- 相同请求不会重复生成；
- 暂停摄像头后自动取图停止且状态持续可见；
- 暂停睡眠提醒后仍保存用户已授权的数据，但不主动提醒；
- 删除风险图片后页面和存储记录一致；
- 家属页不展示连续直播和完整生命体征曲线。

## 8. 来访确认扩展模块

该模块用于展示可扩展业务流程，只识别“发生了一次来访并等待本人确认”。当前没有门铃或门外摄像设备，不在开门前判断门外人员，不做人脸身份识别，不输出诈骗结论。

### 8.1 扩展入口

展示：

- 待确认来访者数量；
- 最近一位来访者的时间和缩略图或占位头像；
- 家人名单数量。

### 8.2 二级页面

页面包含三个区域：

1. 待确认来访者；
2. 最近来访者；
3. 家人名单。

每条待确认记录支持：

- 是家人；
- 认识的人；
- 不认识；
- 暂时不确定。

确认后更新来访者记录。选择“是家人”时可补充姓名或称呼，并加入家人名单。

### 8.3 提醒规则

- 每次新访问事件只主动询问一次；
- 未确认记录保留在待确认区域；
- 同一次访问不因重复识别连续提醒；
- 提示使用“有一位来访者需要确认”等中性表达。
- 页面不出现“诈骗人员”“危险人物”或身份识别结果。

### 8.4 来访确认验收

- 能显示待确认来访者、最近来访者和家人名单；
- 能完成一次身份确认；
- 选择“是家人”后名单正确更新；
- 相同访问事件不重复主动询问；
- 可使用预置来访数据重复演示；
- 所有回放和人工事件显示正确来源；
- 不生成诈骗、危险等级或真实身份结论。

## 13. 文案规则

- 老人端只写老人需要看的生活信息和操作；
- 工程术语只放在工程台；
- 不在老人端写测试说明、研发背景、答辩话术和防御性说明；
- 不使用“演示任务”等与老人生活无关的名称；
- 少用抽象、公文化的词，优先描述具体动作和结果；
- 无数据时只说明“暂时没有新的记录”，不补充冗长解释；
- 风险提示使用“位置 + 发现内容 + 建议动作”的结构。

- 数据缺失时写“暂未同步”，不写0或“正常”；
- 设备原生异常事件写“设备提示这项数据需要关注”，不写疾病名称；
- 家属通知直接说明老人希望得到什么帮助。

示例：

- “走廊中间有一个纸箱，建议移到墙边。”
- “昨晚睡了7小时20分钟，平均呼吸频率是每分钟16次，平均心率是每分钟62次。”
- “最近两晚睡眠时间和平时有些不同。您今天感觉怎么样？”
- “我需要家人帮忙移开走道里的纸箱。”
- “门口有一位来访者，请确认是否认识。”

## 16. 无感睡眠伴侣能力与接口闸门

萤石官方资料确认无感睡眠伴侣能够通过毫米波无感监测呼吸频率和心率，提供睡眠报告，并具备离床未归、心率异常和体动异常等设备能力。桌面版公开参数中的呼吸率范围为6—40次/分、精度为1次/分。

产品能力是否启用，以比赛账号、实际设备型号和开放接口实测为准：

1. 若接口返回夜间汇总，展示昨晚平均呼吸频率、平均心率和多日趋势；
2. 若接口返回时间序列，增加夜间趋势、最低值和最高值；
3. 若接口返回设备原生异常事件，按原始事件展示“需要关注”并询问本人；
4. 若接口返回实时离床事件且延迟通过测试，才增加实时离床提醒；
5. 若开放接口暂未提供某字段，使用授权导出数据完成离线验证，正式页面显示“暂未同步”；
6. 预置数据只用于演示与自动化测试，不能计入真实设备效果。
