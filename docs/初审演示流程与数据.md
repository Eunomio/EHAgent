# 初审演示流程与数据

## 两个安装版本

- 演示内容与实际功能版：`assembleDemoDebug`，安全页可在“走廊画面”和“实时画面”之间切换。
- 实际功能版：`assembleActualDebug`，不打包内置视频，也不显示画面切换和模拟睡眠数据入口。

## 录制顺序

1. 打开现有“安全”页。走廊画面打开后自动检查，第一段结束时截取当前画面并调用现有视觉分析能力，等待结果返回后显示识别依据、风险等级和整理建议。
2. 点击“我已整理好”，第二段画面重新分析地面上仍然存在的玩具车；必须显示本次分析结果后才能继续。只要结果包含绊倒风险，最低按中风险提醒整理。
3. 再次整理后，第三段继续复查遗漏的玩具车；继续整理后，第四段检查没有障碍物的画面。具体标题、物品数量和建议使用当次视觉分析结果，不使用预设检测文案。
4. 打开现有“睡眠”页。查看最近7晚柱形趋势，点击柱形可切换逐晚数据。
5. 返回首页，点击现有“主动关怀”卡片，在“问小安”页完成问询。
6. 今晚老人再次睡不着时，在现有“问小安”页说“小安，播放白噪音”，确认播放操作。

## 主动问询台词

- 小安：我发现您昨天半夜醒了以后，过了好久才睡着，是发生什么事了吗？
- 老人：哎呀，我昨晚起来以后再躺下就睡不着了，白天也没有精神。
- 小安：听起来这次起夜影响了后面的休息。您当时是身体不舒服，还是脑子比较清醒、一直睡不着？
- 老人：身体没有不舒服，就是脑子清醒了，后来一直睡不着。
- 小安：明白了。今晚您再睡不着，可以试试听一会儿轻柔的白噪音。您叫我，我就给您放。
- 老人：好，睡不着我叫你。
